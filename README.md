# AvofsionTDf — портфолио веб-разработчика

Одностраничный сайт-портфолио (RU/EN) в стиле premium dark. Контакт: https://t.me/Avofs

## Технологии
TanStack Start, React 19, Tailwind CSS 4, TypeScript, хостинг Netlify.

## Локальный запуск
```bash
pnpm install
pnpm dev   # http://localhost:3000
```
